# AGENTS.md: NHL comparator

The running list of data surprises and the ground rules. Add to it whenever a gate or a reader's correction teaches us one. Decisions and their evidence live in `research/` (start with `research/README.md`).

## Ground rules

- No `git init` until Drew says so. Raw response caches live under `data/raw/` (gitignored) and never go to a public repo.
- Every outside request goes through `research/lib/fetch.mjs` (one request per 1.5 s per process, forever cache under `data/raw/<host>/`, backoff on 429/5xx, a user agent that names the project). One process per host at a time. Never call `fetch` directly. A research agent that fetches is given the helper by path and a request budget, and its `data/raw/logs/fetch.log` lines are checked afterwards. "Research" is not a licence to crawl.
- A probe characterizes a source (span, grain, floors, three spot checks per decade). It is not a harvest. A harvest is a decision Drew makes after the license question is settled in `research/beachhead.md`.
- Sports Reference pages (Hockey-Reference) are receipts only: one page per lead at reader pace, never a harvest; the Wayback Machine when the live site blocks.
- The model never counts. Agents extract rows with receipts (`{ url, quote, note?, retrieved? }`); code joins, counts and ranks.

## What the probes found (2026-10-21, research phase)

The four reports under `research/` have the receipts. These are the ones that change code.

- **The stats REST serves per-game rows in bulk from 1917-18** (`api.nhle.com/stats/rest/en/skater/summary?isAggregate=false&isGame=true&limit=-1&cayenneExp=...`), capped at 10,000 rows per query with `total` saturating at 10,000 and `start=10000` returning `[]`. Window by month. One October of 1981 is 4,074 rows in one 2 MB call. The whole ledger is about 800 requests.
- **Per-stat floors differ by endpoint.** Hits, blocks, giveaways and takeaways exist from 1997-98 only in the api-web boxscore; the REST has them from 2005-06. The boxscore has no SHG or GWG keys; the game log and the REST do. Goalie OT losses are folded into L before 2005-06.
- **1917-18 has 36 regular-season game ids but 34 games in the season table** (the Wanderers' defaulted games), and 7 playoff ids of which 5 are the Stanley Cup Final against a non-NHL (PCHA) opponent, team id 7288. 1917020037 is a 404.
- **Game types:** 1 preseason, 2 regular, 3 playoffs (the 2019-20 qualifying round included: 2019030021–024), 4 All-Star (1959040013 has skater stats; exclude it). Playoff ids are `{season}03{round}{series}{game}`.
- **Neutral sites** from 1993-94 carry `neutralSite: true` and the venue in `club-schedule-season`.
- **Scratches live in `gamecenter/{id}/right-rail`, not the boxscore, and pre-modern lists are "roster minus dressed"** (1950 MTL shows 15, Béliveau among them). The boxscore lists the dressed lineup, 0-point skaters included; before 1997-98 TOI is 0 or absent for everyone.
- **ESPN's site API returns 403 to the helper's honest user agent and 200 to a browser's.** We don't wear the browser's. ESPN box scores start 1993-94 anyway.
- **sportsdataverse NHL files:** the year in a file name is the season's end year (`player_box_2010.csv` is 2009-10), but the per-season schedule files label by start year. `player_box` and `team_box` have no game id, season or date, and their 2018 files are byte-identical to 2019 (2017-18 missing). `skater_box` and `goalie_box` are right (McDavid 2017-18: 82 rows, 41 G, 108 P). Only goalies carry a starter flag; nothing carries a DOB. Every 2010-11 playoff game in `nhl_schedule_2011.csv` says venue "Honda Center".
- **The NHL re-ruled franchise history on 2026-09-24:** Winnipeg = Jets 1979-96 + Thrashers 1999-2011 + Jets 2011-; the inactive Coyotes keep only 1996-2024; Utah (2024, the Mammoth since 2025-26) inherits nothing. Wikipedia's "1972-1996" for the Jets is wrong (the NHL counts from 1979; WHA years are not NHL). A franchise id is a versioned ruling file the build can re-map.
- **Season length by era:** 22 (1917-18), 18 of 20 scheduled (1918-19), … 84 (1992-94, with two neutral "home" games a team), 48 (1994-95, 2012-13), none (2004-05), 68–71 unequal (2019-20, ranked by points percentage), 56 (2020-21), 82, and 84 from 2026-27.
- **Known answers that reproduce from the API:** Gretzky's 50th of 1981-82 in EDM's 39th game (1981-12-30 vs PHI, 5 goals); Richard's 50th in game 50 of 50 (1945-03-18 at BOS); Lemieux's 50th in his 44th game, PIT's 46th (1989-01-20); Howe 1952-53 49 G, 95 P in 70; Orr 1970-71 +124; Brodeur 48 wins in 2006-07 and 691 career; McDavid's 1,000th point 2024-11-14 vs NSH in game 659 (our brief had the date wrong); Ovechkin's 895th 2025-04-06 at NYI in game 1,487. `records.nhl.com/site/api/milestone-*` carries the league's own `skaterGamesPlayed` and `teamGamesPlayed` for these and agrees.
- **Crosswalks:** the Chadwick register's `key_sr_nhl` is filled on 9 rows and useless. Wikidata has 14,040 people with an NHL.com id (P3522), 14,012 with a DOB, 8,523 with a Hockey-Reference id (P3598; P3567 is the Hall of Fame id). The Hockey Databank's Master table carries `hrefID` and a DOB for 8,543 of 8,670 people and no NHL id, so Wikidata is the join.
- **Two independent lineages before 1987:** the NHL's league-office archive (digitized 2011–2017, "more than 24,000 games from 1917 through 1987") behind the API, and the Hockey Summary Project. Hockey-Reference is a blend (Dan Diamond and Associates plus HSP), with player game logs from 1987-88. Every third-party per-game file from 1987-88 on is an NHL API pull, so two of them agreeing is one source twice.
- **Store the local game date.** A 7 pm Pacific puck drop is the next UTC day. (The API's date field semantics are still to be confirmed when the harvester is written.)

## Decisions at the first build (2026-10-22)

- **One source for every season, not two.** The beachhead proposed sportsdataverse for 2009-10 on and the REST for earlier seasons. The release files carry no shorthanded, game-winning or overtime goals, so the two layers would have had different stat catalogs across a seam; the ledger reads the REST for every season instead, and the daily refresh refetches the running season through the same throttled helper (about a dozen requests). The posture argument the beachhead made still stands; the seam cost more than it bought.
- **Repo shape:** code MIT (`LICENSE`), the data's terms in `data/NOTICE`, `data/raw/` gitignored (the whole REST cache is a few hundred MB and refetchable in 25 minutes), ledgers committed.
- **Playoff games against non-NHL opponents** (the 1918–1926 Finals against the PCHA and WCHL) are excluded by the builder, which lists them at build time; the Method says so.
- **Team codes are the codes of the day** (the REST's `teamAbbrev`); a franchise ruling file (`data/ref/franchises.json`, with the NHL's 2026-09-24 re-ruling) is the next step when team pages arrive.
- **Season labels:** seasons are stored as their start year and printed "1981-82" (`fmtSeason`); `since` in the URL is the start year.
- **The ledger ships split.** The skaters' core columns (season, post, the team's game number, the team, goals, assists, penalty minutes) are `src/data/skaters.json`, 2.3 MB gzipped, and ship with the page; the rest (date, home, opponent, result, shots, plus-minus, power-play, shorthanded and game-winning goals) are `skaters-x.json`, 7 MB gzipped, loaded the first time a query or the panel needs them (`App.jsx`: `colsNeeded`, `hasCols`, `mergeExtra`). Points are goals plus assists, derived, not stored. The whole file was 10 MB gzipped, which is too much for a page load.
- **The Databank cross-check** (`pipeline/check-databank.mjs`, Hockey Databank v13 through 2017-18, joined through Wikidata's Hockey-Reference ids with the letter directory stripped): skaters 39,329 of 40,144 player-seasons match exactly on GP, goals and assists (97.97%), 99% or better from the 1970s on, 61% in the 1910s and 74% in the 1920s, where the league's 2017 re-audit changed assists and a few games; goalies 97.4%, with a 1960s dip to 77% on wins and games played that nobody has explained yet (a lead: shared-decision games, or the re-audit). The Scoring table lists goalies too (skip `pos` G), and a roster row with GP 0 is not a season.
- **A first NHL season is not a rookie season.** Gretzky's 137 points in 1979-80 outrank Selänne's 132 on the first-season board because the league's rookie rules exclude his WHA year; the landings say "first NHL season" and the Method says why.
- **1917-18 lists 36 regular-season games and played 34**: 1917020035 and 1917020036 (the Wanderers' defaulted games) have no player rows and are dropped before the schedule is numbered, so Montreal's and Toronto's game numbers match the season table.
- **Early playoff goalie rows carry shots against that the regular season lacks** (1929-30), so floors are read from regular-season rows only; a shots-against of 0 against a goal is a placeholder and reads as missing.
- **The committed ledgers are 44 MB of JSON** (17.5 + 23.7 + 3.1). A refresh commit adds about 10 MB to the history; a release asset or an R2 bucket for the ledgers is the next step if that grows old.
